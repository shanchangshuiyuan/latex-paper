\chapter{基础理论与相关技术}
本章介绍了虚拟现实复杂动画网格的注视点渲染技术的相关理论基础知识，包括人类视觉系统及动画网格渲染流程中核心概念。此外，还介绍了系统开发所采用的渲染引擎unity，为后续研究工作提供支持。

\section{人类视觉系统}
人类视觉系统（Human Visual System, HVS）是人类用于感知和理解视觉信息的复杂系统，由眼球光学结构、视网膜光感受器、视神经传导通路以及大脑视觉皮层组成。HVS 具备高分辨率的中央视野和低分辨率的周边视野，能够高效地处理复杂视觉场景，为注视点渲染技术提供了生理学基础。

\subsection{人眼工作机制}
光线首先通过角膜进入眼睛，随后穿过瞳孔，瞳孔的大小由虹膜调节，以控制进入眼睛的光量。接着，晶状体对光线进行进一步折射与变焦，确保不同景深的物体准确成像于视网膜内层\cite{2-1}。视网膜作为视觉信号的接收端，包含视杆细胞与视锥细胞两类光感受器。视杆细胞对光线非常敏感，主要负责在低光照下的视觉，能够感知亮度但不分辨颜色；视锥细胞主要负责色彩感知和细节识别。这些光感受器将光信号转化为电信号，并通过视神经将信号传递至大脑。视觉信号达到大脑之后，首先在初级视觉皮层进行处理，该区域主要负责基本的视觉特征分析，如边缘、颜色和运动等。在此之后，信号被传递到多个高级视觉区域，这些区域负责进一步整合和分析视觉信息，以识别物体、面孔和场景。人眼眼球结构如图\ref{fig:eye_structure}所示\cite{2-2}。

HVS 的空间感知特性具有显著的非均匀性，这种非均匀性通常与视网膜光感受器的差异化分布相关\cite{2-3}。视网膜中心直径约 1.5 毫米的区域被称为中央凹区域，该区域由高密度的视锥细胞紧密排列而成，几乎不含视杆细胞。在明亮环境下，中央凹区域能够提供视场中最高分辨率的视觉信息与最丰富的色彩层次。相比之下，视网膜的外围区域主要由视杆细胞构成。随着偏心率的增加，即距离中央凹区域越远，视锥细胞密度急剧下降，而视杆细胞密度逐渐上升，导致视觉敏感度迅速衰减。

正是由于视锥与视杆细胞的这种不均匀分布，人眼对中心视野与周边视野的感知能力呈现出巨大的差异：中央凹区域专注于高频细节与色彩的精确采样，而周边区域则对图像细节感知较为模糊。注视点渲染技术正是利用这一生理学特性，通过聚焦于视觉中心区域，将有限的计算资源集中分配至观察者关注的重点区域，从而在有限的硬件条件下最大程度提升渲染效率。

\subsection{眼动行为}
人眼在观察外部世界时，眼球会执行一系列动态的运动，这些运动统称为眼动行为。根据其功能与形态特征，眼动主要可分为三种基本模式：注视、扫视和平稳跟踪。

注视是指眼球在某一位置保持相对静止的状态，持续时间从几百毫秒到几秒不等。在这段时间内，大脑可对落在中央凹区域的视觉信息进行深入加工，包括颜色识别、形状分析与运动感知等。绝大多数视觉信息的获取发生在注视阶段，其持续时间与空间分布受到目标显著性、场景复杂度以及观察者先前经验的共同调节\cite{2-4}。

扫视是指眼球快速移动，能在极短时间（通常为几十毫秒）内将视线从一个注视点转移到另一个注视点。在扫视过程中，视觉输入会被暂时抑制，以隐藏视网膜的运动模糊，这种现象被称为扫视抑制。值得注意的是，扫视后视觉敏感度并非立即恢复至最佳状态，而是伴随眼漂移和微扫视等不自觉的眼球运动，在数百毫秒内逐步提升对细节的分辨能力\cite{2-5}\cite{2-6}。


平稳跟踪是眼球为跟随运动物体而进行的平滑、连续的运动。这种运动能使目标图像稳定在中央凹区域，从而保持对其细节的持续解析。平稳跟踪的效果受目标速度、运动轨迹的可预测性以及个体追踪能力的影响，它在动态视觉环境中起着维持视觉连贯性的重要作用\cite{2-7}。

眼动行为是视觉注意与信息获取的外在表现，与注意力分配、刺激特征、情绪状态及认知负荷等因素密切相关\cite{2-8}。人眼通过灵活组合上述眼动行为，实现了在复杂环境中高效、有序的视觉采样。对眼动行为的深入研究，不仅有助于揭示视觉感知与认知处理之间的动态关联，也为注视点渲染、虚拟现实等技术的优化提供了重要的理论依据与实践指导。也为注视点渲染、虚拟现实等技术的优化提供了重要的理论依据与实践指导\cite{2-9}\cite{2-10}。


\subsection{对比敏感度函数}

在视觉感知中，对比度用来描述视觉刺激中亮度或颜色的相对差异，是构建图像轮廓、纹理及细节的基础。对比敏感度（Contrast Sensitivity, CS）定义为视觉系统能够辨别的最小对比度阈值的倒数；该值越高，表明人眼对微小差异的感知能力越强。HVS 对空间频率的响应具有带通特性：通常对中等频率信息最为敏感，而在极低或极高频率下对比敏感度会显著下降。

通过系统测量不同空间频率下的对比敏感度，可绘制出对比敏感度函数（Contrast Sensitivity Function, CSF），该函数描述了人眼分辨能力随空间频率变化的规律。CSF 在视野中表现出显著的空间非均匀性，受视网膜偏心率调制明显：对比敏感度在中央凹处达到峰值，并随偏心率增加而单调衰减。此外，不同区域的 CSF 曲线形状也有显著差异：中央凹对高频细节的感知能力较强，衰减缓慢；而外围区域的敏感度在达到峰值后急剧下降，表明外围视觉对高频细节的解析能力受到严重限制。

CSF 存在一个关键参数称为截止空间频率，超过该频率的细节人眼无法有效分辨，且该截止值随偏心率增大而降低。同时外围视觉中存在一个介于检测截止频率与辨别截止频率之间的频率区间，称为混叠区。在该区域内，视觉系统虽能通过视网膜神经节细胞感知到信号的存在，却受限于欠采样而无法正确解析其结构细节。这一特性对注视点渲染技术具有重要指导意义：若仅依据分辨能力（分辨截止频率）简单降低外围采样率，极易导致高频信号落入混叠区而产生可察觉的伪影。因此，高效的渲染算法需结合 CSF 模型，在混叠区内采取适当的对比度保持或增强策略，以在最大化渲染效率的同时，确保视觉感知的完整性与稳定性。

\section{动画网格渲染流程}

动画网格的渲染是将离散的时变几何数据转换为连续的二维屏幕图像的过程，该过程依赖于 CPU（Central Processing Unit）与 GPU（Graphics Processing Unit）的协同计算，构成了实时渲染管线。针对具备动态骨骼形变的动画网格，其渲染流程不仅涉及静态的几何投影，还包含复杂的蒙皮计算与属性插值。根据数据流的传递与处理逻辑，完整的渲染管线可严格划分为应用阶段、几何阶段和光栅化阶段。


\subsection{应用阶段}

应用阶段由 CPU 主导，主要负责场景图的遍历、物理仿真更新、渲染状态的设置以及几何数据的预处理。在此阶段，系统首先执行视锥体剔除算法，通过构建相机的视锥体几何包围盒，检测场景中的动画网格包围盒是否位于可视范围内。对于完全位于视锥体之外的物体，直接丢弃其绘制指令，从而避免后续 GPU 的无效计算资源消耗。对于判定为可见的动画网格，CPU 需将其模型数据如顶点位置、法线、纹理坐标及骨骼索引与权重等加载至显存，并配置全局渲染参数。参数包括定义观察矩阵所需的视点位置 $P_{eye}$、观察方向 $\vec{d}$ 及上向量 $\vec{u}$，以及光源的位置、颜色及衰减因子。该阶段的最终输出是包含几何信息与材质属性的渲染图元集合，并通过绘制Draw Call 触发 GPU 进入下一阶段。




应用阶段主要由 CPU 负责，其任务是将渲染所需的数据加载到显存并设置渲染状态。这些数据主要包括模型数据和纹理图像，其中模型数据是指模型的顶点坐标和纹理坐标。此外，该阶段还需向 GPU 提供场景数据，包括相机属性和光源属性。相机在三维场景中扮演着观察者的角色，其属性主要包括位置、朝向、上向量、视角大小、近裁剪平面和远裁剪平面。

分析视锥体确定视野内的物体，利用裁剪算法剔除不可见的冗余几何数据，仅对可见区域的模型进行渲染处理，在维持视觉完整性的同时降低计算量，提高渲染效率。

光源在场景中负责照明，影响物体的可见性和光照效果。光源属性主要包括光源类型、光源位置、光源颜色、光源亮度以及光源衰减参数。

应用阶段通过模型的创建和数据结构化，最终输出渲染所需的几何信息，即渲染图元。渲染图元用于描述基本几何形状，主要包括点、线段和三角形面，这些形状是构成复杂三维图形的基础元素。与渲染相关的信息存储在顶点的数据结构中。

\subsection{几何阶段}

几何阶段的运算任务主要由 GPU 负责，对上一阶段 CPU 传来的数据进行进一步处理，将渲染图元的三维信息投射到二维屏幕空间上，该阶段可细分为如下流程：

顶点着色器阶段是 GPU 流水线的起始阶段，负责接收应用阶段生成的顶点数据，其功能仅限于对当前顶点进行坐标变换和逐顶点光照处理，无法创建或删除顶点。外壳着色器、细分器和域着色器共同构成细分阶段，该阶段与几何着色器均为可选流程允许开发者对顶点进行增删改操作。此外，投影操作也是顶点坐标变换的一部分。

顶点的坐标变换涉及多种坐标系统，这些系统根据参照物的不同可分为模型空间、世界空间、观察空间、齐次裁剪空间以及屏幕空间。因此，顶点的坐标变换可分解为模型变换、视图变换和投影变换。每个变换环节共同完成从局部坐标到屏幕坐标的完整过程。几何阶段结束后，输出经过变换和裁剪处理的顶点数据，包括顶点的屏幕坐标、颜色、纹理坐标以及其它必要属性。这些顶点数据随后被传递至光栅化阶段。

\subsection{光栅化阶段}

光栅化阶段主要由 GPU 负责，接收几何阶段的顶点数据，计算渲染图元覆盖像素并进行着色处理，输出最终渲染图像。该阶段可细分为如下流程：

三角形设置阶段会计算光栅化一个三角形网格所需的信息。由于几何阶段输出的是二维屏幕空间的三角形网格顶点，即三角形网格每条边的两个端点，因此，需要计算出每条边上的像素坐标，从而得到整个三角形网格的像素覆盖情况。

三角形遍历阶段基于渲染图元边界的像素坐标检查屏幕上的每一个像素是否被三角形网格所覆盖，被覆盖的区域将生成一个片元。所谓片元，不是真正意义上的像素，而是包含了多种状态的集合，这些状态被称为片元数据，由三角形的顶点信息进行插值计算得到，用于最终计算出对应像素的颜色。

片元着色器根据插值得到的片元数据，为每一个片元计算出对应像素的颜色，结果仅影响单个片元并传递给下一阶段进行处理。

逐片元操作负责对每个片元进行测试并混合输出。测试操作包括透明度测试、模板测试和深度测试，主要决定片元的可见性。透明度测试用于检测片元的透明度，仅当透明度值达到设定阈值时才绘制该片元。模板测试常用于限制渲染区域，便于在不同区域应用特定渲染算法。深度测试则比较片元的深度值与深度缓冲区中的现有值，以确定是否更新该像素的颜色。通过测试的片元将进入混合操作阶段。在生成一帧图像时，逐个渲染物体模型，每次渲染都会刷新颜色缓冲区，而非首次渲染时，颜色缓冲区中保留了上一次的渲染结果。因此，混合操作可以选择直接覆盖颜色，或根据片元的不透明度与已有颜色进行混合，最终生成完整的渲染图像。

整个光栅化阶段包括从三角形的屏幕空间映射到最终生成像素颜色的完整过程，而一般意义上的像素处理阶段是光栅化阶段中的一个关键环节，专注于对每个片元或像素进行具体的计算和处理，属于光栅化阶段的细化内容。

其次，详细剖析了三维动画网格的标准渲染流程，将其划分为应用阶段、几何阶段与光栅化阶段，并阐述了各阶段中CPU与GPU协同工作的具体任务，包括顶点处理、图元光栅化及片元着色等关键步骤。这一流程是理解和优化渲染性能的基础。
最后，介绍了本研究选用的Unity3D渲染引擎，概述了其在实时图形渲染、物理仿真、动画系统及跨平台部署等方面的强大功能，说明了其作为系统开发平台能够为后续注视点渲染算法的实现与验证提供有力的技术支持。
