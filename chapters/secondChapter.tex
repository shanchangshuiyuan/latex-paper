\chapter{基础理论与相关技术}
本章介绍了虚拟现实复杂动画网格的注视点渲染技术的相关理论基础知识，包括人类视觉系统及动画网格渲染流程中核心概念。此外，还介绍了系统开发所采用的渲染引擎unity，为后续研究工作提供支持。

\section{人类视觉系统}
人类视觉系统（human visual system， HVS）是人类用于感知和理解视觉信息的复系统，其包括眼睛、大脑和其他相关的生物学组件。具备高分辨率中央视野和低分辨率外围视野的特性，能够高效处理复杂视觉场景，帮助人类感知、理解和与环境交互。

\subsection{人眼工作机制}
光线首先通过角膜进入眼睛，随后穿过瞳孔，瞳孔的大小由虹膜调节，以控制进入眼睛的光量。接着，光线经过晶状体进一步折射光线并调节焦距，以确保不同距离的物体能够在视网膜上清晰成像。视网膜位于眼球的内层，包含两种光感受器：视杆细胞和视锥细胞。视杆细胞对光线非常敏感，主要负责在低光照下的视觉，能够感知亮度但不分辨颜色；而视锥细胞主要负责色彩感知和细节识别。视网膜中的这些光感受器将光信号转化为电信号，并通过视神经将信号传递至大脑。视觉信号达到大脑之后，首先在初级视觉皮层进行处理，该区域主要负责基本的视觉特征分析，如边缘、颜色和运动等。在此之后，信号被传递到多个高级视觉区域，这些区域负责进一步整合和分析视觉信息，以识别物体、面孔和场景。

HVS 的感知特征在视野上是不均匀的，这种不均匀性通常与视网膜光感受器的不均匀分布相关。中央凹是视网膜中心的一小块区域，直径约 1.5 毫米，由密集排列的视锥细胞组成，几乎不含视杆细胞。在明亮光照下，中央凹能够提供最清晰、最丰富的视觉信息。相比之下，视网膜的外围区域主要由视杆细胞构成。随着偏心度增加，即距离中央凹越远，视杆细胞数量逐渐增多，而视锥细胞则逐渐减少。

由于视锥细胞和视杆细胞的不均匀分布，人眼能够灵活适应不同的视觉需求。其中，中央凹区域提供高分辨率的细节和颜色感知，而外围区域对图像的细节感知较为模糊。注视点渲染技术正是基于这一视觉特性，聚焦于视觉中心区域，以更高效地分配计算资源，从而在有限的硬件条件下最大程度提升渲染效率。

\subsection{眼动行为}
人眼的眼动行为是指在观察目标物体或场景时眼球的运动模式，主要包括三种类型：眼跳、注视和平稳跟踪。

眼跳是指眼球快速移动，将视线迅速从一个物体转移到另一个物体上，通常在毫
秒级别完成。这在个过程中，视觉输入会受到抑制，以隐藏视网膜的运动模糊，这种现象被称为扫视抑制。需要注意的是，眼跳后视觉锐度的恢复并非瞬时完成，而是一个渐进的过程，通常伴随眼漂移和微扫视等不自觉的眼球运动，这些运动会随着时间的推移逐渐提高对高空间频率的视觉敏感度。

注视是眼睛在某一位置上的静止状态，持续时间从几百毫秒到几秒不等。这一行为允许大脑对该区域的视觉信息进行深入处理，包括分析颜色、形状、运动等特征。因此，多数的视觉信息是通过注视获取的。注视的时间和位置，往往受到视觉目标的重要性、复杂性以及先前经验的影响。

平稳跟踪是指眼睛随着移动物体进行的平滑运动，实现对移动对象的持续关注。平稳追踪的有效性和稳定性与物体的速度和方向变化有关，帮助观察者在复杂的视觉环境中做出快速反应。

眼动行为在获取和处理视觉信息的过程中发挥着重要作用，与多个因素密切相关，包括视觉注意机制、外部刺激的特性、个体的情绪状态和认知负荷等。人眼的眼动行为展示出高度的适应性和灵活性，能够在多变的环境中有效地获取和整合视觉信息。这些特点不仅揭示了人类视觉系统的复杂性，还为理解视觉注意和信息处理提供了重要的理论基础。通过深入研究眼动行为的特征和机制，我们可以更好地理解视觉感知的动态过程，并为虚拟现实技术、注视点渲染技术等提供指导。

\subsection{视觉敏锐度}
视觉敏锐度是指辨别物体形状和细节的能力。作为注视点渲染中广泛使用的主要 HVS 特征，视觉敏锐度具有以下特性：

中央凹 / 周边视觉：人类的视觉敏锐度在整个视野范围内并不均匀。当人注视物体时，中央凹视觉场景的细节可以被识别；然而，周边视觉场景则无法清晰地识别。也就是说，人类视觉系统（HVS）在人类视觉区域的中央凹处具有更高的视觉敏锐度，这是中央凹渲染的基础。

融合视觉：双眼运动使单眼图像融合，产生双眼视觉。在融合视觉中，当用双眼观看时，物体被感知为单一统一物体的区域称为 Panum 融合区。Panum 融合区以外的场景被识别为“重像”会导致图像质量下降，视觉真实感下降。它可以简化 Panum 融合区域之外的场景，从而实现高效的注视点渲染。

主导眼：双眼在 HVS 中对视觉刺激的敏感度不同，即一只眼睛比另一只眼睛更敏感，敏感度更高的眼睛被称为主导眼。在对双目显示器进行注视点渲染时，可以为非主导眼分配较少的计算资源，以加快渲染速度。

\subsection{对比敏感度}

对比度是描述图像或视觉刺激中亮度差异或颜色差异的度量，它表示亮度或颜色之间的差异程度。而对比度的倒数通常称为对比度敏感性，它表示在特定的空间频率和时间频率下，人眼能够察觉到的最小对比度变化，较低的对比度敏感性值表明视觉系统对亮度或颜色差异更加敏感。不同的空间和时间频率会影响对比度感知的能力，在某些频率下，人眼可以察觉微小的亮度或颜色差异，而在其他频率下，需要更大的差异才能察觉到。通过测量不同频率下的对比度敏感性，可以构建对比敏感度函数（CSF），该函数描述了人类视觉系统识别图案差异的能力，该能力与空间频率有关。给定空间频率的对比敏感度在中央凹处最高，并随着偏心率的增加而降低。对比敏感度取决于多种因素，例如目标图案的大小、对比度和视角。

对比敏感度和空间频率之间的关系在整个视野中是不同的。一般来说，随着空间频率的增加，中央凹处的对比敏感度会逐渐下降，而外围区域的对比敏感度则会急剧下降。对比敏感度函数有一个截止空间频率，超过该频率则无法辨别更高的频率。截止空间频率取决于视野中图像块位置的偏心率。

\section{动画网格渲染流程}

三维图形的渲染是指通过一系列步骤将三维数据转换为二维图像，涵盖了从场景构建到最终输出的各个方面。在渲染流程中，CPU (Central Processing Unit) 和 GPU
(Graphics Processing Unit) 合力渲染图像，每个步骤都涉及复杂的计算和处理，以确
保最终图像的高质量和真实感。一个完整的渲染流程可以分为以下三个阶段：应用阶
段、几何阶段和光栅化阶段。

\subsection{应用阶段}
应用阶段主要由 CPU 负责，其任务是将渲染所需的数据加载到显存并设置渲染状态。这些数据主要包括模型数据和纹理图像，其中模型数据是指模型的顶点坐标和纹理坐标。此外，该阶段还需向 GPU 提供场景数据，包括相机属性和光源属性。相机在三维场景中扮演着观察者的角色，其属性主要包括位置、朝向、上向量、视角大小、近裁剪平面和远裁剪平面。

分析视锥体确定视野内的物体，利用裁剪算法剔除不可见的冗余几何数据，仅对可见区域的模型进行渲染处理，在维持视觉完整性的同时降低计算量，提高渲染效率。

光源在场景中负责照明，影响物体的可见性和光照效果。光源属性主要包括光源类型、光源位置、光源颜色、光源亮度以及光源衰减参数。

应用阶段通过模型的创建和数据结构化，最终输出渲染所需的几何信息，即渲染图元。渲染图元用于描述基本几何形状，主要包括点、线段和三角形面，这些形状是构成复杂三维图形的基础元素。与渲染相关的信息存储在顶点的数据结构中。

\subsection{几何阶段}

几何阶段的运算任务主要由 GPU 负责，对上一阶段 CPU 传来的数据进行进一步处理，将渲染图元的三维信息投射到二维屏幕空间上，该阶段可细分为如下流程：

顶点着色器阶段是 GPU 流水线的起始阶段，负责接收应用阶段生成的顶点数据，其功能仅限于对当前顶点进行坐标变换和逐顶点光照处理，无法创建或删除顶点。外壳着色器、细分器和域着色器共同构成细分阶段，该阶段与几何着色器均为可选流程允许开发者对顶点进行增删改操作。此外，投影操作也是顶点坐标变换的一部分。

顶点的坐标变换涉及多种坐标系统，这些系统根据参照物的不同可分为模型空间、世界空间、观察空间、齐次裁剪空间以及屏幕空间。因此，顶点的坐标变换可分解为模型变换、视图变换和投影变换。每个变换环节共同完成从局部坐标到屏幕坐标的完整过程。几何阶段结束后，输出经过变换和裁剪处理的顶点数据，包括顶点的屏幕坐标、颜色、纹理坐标以及其它必要属性。这些顶点数据随后被传递至光栅化阶段。

\subsection{光栅化阶段}

光栅化阶段主要由 GPU 负责，接收几何阶段的顶点数据，计算渲染图元覆盖像素并进行着色处理，输出最终渲染图像。该阶段可细分为如下流程：

三角形设置阶段会计算光栅化一个三角形网格所需的信息。由于几何阶段输出的是二维屏幕空间的三角形网格顶点，即三角形网格每条边的两个端点，因此，需要计算出每条边上的像素坐标，从而得到整个三角形网格的像素覆盖情况。

三角形遍历阶段基于渲染图元边界的像素坐标检查屏幕上的每一个像素是否被三角形网格所覆盖，被覆盖的区域将生成一个片元。所谓片元，不是真正意义上的像素，而是包含了多种状态的集合，这些状态被称为片元数据，由三角形的顶点信息进行插值计算得到，用于最终计算出对应像素的颜色。

片元着色器根据插值得到的片元数据，为每一个片元计算出对应像素的颜色，结果仅影响单个片元并传递给下一阶段进行处理。

逐片元操作负责对每个片元进行测试并混合输出。测试操作包括透明度测试、模板测试和深度测试，主要决定片元的可见性。透明度测试用于检测片元的透明度，仅当透明度值达到设定阈值时才绘制该片元。模板测试常用于限制渲染区域，便于在不同区域应用特定渲染算法。深度测试则比较片元的深度值与深度缓冲区中的现有值，以确定是否更新该像素的颜色。通过测试的片元将进入混合操作阶段。在生成一帧图像时，逐个渲染物体模型，每次渲染都会刷新颜色缓冲区，而非首次渲染时，颜色缓冲区中保留了上一次的渲染结果。因此，混合操作可以选择直接覆盖颜色，或根据片元的不透明度与已有颜色进行混合，最终生成完整的渲染图像。

整个光栅化阶段包括从三角形的屏幕空间映射到最终生成像素颜色的完整过程，而一般意义上的像素处理阶段是光栅化阶段中的一个关键环节，专注于对每个片元或像素进行具体的计算和处理，属于光栅化阶段的细化内容。

\section{本章小结}

本章系统阐述了虚拟现实复杂动画网格注视点渲染技术所涉及的核心理论基础。首先，本文深入分析了人类视觉系统的关键特性，包括视网膜中央凹与周边视觉在分辨率上的显著差异、眼动行为的基本模式、视觉敏锐度的空间分布规律以及对比敏感度函数特征。这些视觉感知特性为注视点渲染技术提供了重要的生理学依据，使其能够通过差异化分配计算资源来提升渲染效率。
其次，详细剖析了三维动画网格的标准渲染流程，将其划分为应用阶段、几何阶段与光栅化阶段，并阐述了各阶段中CPU与GPU协同工作的具体任务，包括顶点处理、图元光栅化及片元着色等关键步骤。这一流程是理解和优化渲染性能的基础。
最后，介绍了本研究选用的Unity3D渲染引擎，概述了其在实时图形渲染、物理仿真、动画系统及跨平台部署等方面的强大功能，说明了其作为系统开发平台能够为后续注视点渲染算法的实现与验证提供有力的技术支持。
综上所述，本章奠定的视觉感知理论、图形学渲染流程及工具平台基础，为后续开展面向虚拟现实场景的动画网格注视点渲染算法研究做好了充分的理论与技术准备。
